# 4화 기획: «Yejin Had a Little Lamb» (TUBER 프로젝트(Claude))

작성: 2026-11-22 KST.

## 1. 곡

- 먼저 시도한 «Old MacDonald Had a Farm»과 «Here We Go Round the Mulberry Bush»(예진이 개사판)는 Suno가 "copyrighted material"로 **차단**(각 2테이크, 크레딧 0). 규칙대로 우회 개사는 하지 않고 다음 곡으로 넘어갔습니다.
- 채택: «Mary Had a Little Lamb»(bible/02 8순위) 예진이 판. 1절은 원곡에서 이름만 Yejin으로, 2~5절은 새 가사(털뭉치 둘, 풀밭 깡충, Pip 등장, 낮잠). 원곡의 해 질 녘 대신 **낮잠**으로 바꿔 하늘 고정 규칙(노을 금지)을 지킵니다.
- 채택 테이크 **ca0003f1**: 94.72초, 5절 모두 순서대로, 멜로디 전래곡 일치, 이름은 YEH-jin(/ɛ/+/ɪ/), 품질 8/10. 끝이 갑자기 끊겨 편집에서 1.5초 페이드아웃.
  - 탈락: 6a250192, d3024c64(이름이 "Yejun"으로 들림, d3024c64는 5절 누락·끝 잘림), dfa291f3("Pip"이 "Pig"로 들림).

## 2. 이야기 (새 세트 1곳: Clover Meadow)

예진이가 클로버 들판에 들어오고 아기 양이 폴짝 일어남 → 둘이 나란히(털뭉치 둘, 누가 누구?) → 풀밭을 깡충깡충 → (간주) 큰 나무 주위 술래잡기, Pip이 웅덩이에 등장 → 셋이 한 줄로 앉아 웅덩이 첨벙 → 나무 그늘에서 낮잠 → 엔딩 의식(예진이가 한쪽 눈을 뜨고 손 흔들기, 카메라 빠지기).

## 3. 새 캐릭터와 세트 (고정 디자인)

- 아기 양: 작고 둥근 몸, 구름 같은 곱슬 크림색 털, **연한 복숭아빛 베이지 얼굴**(예진이와 구별), 털 속에 납작하게 숨은 작은 잎 모양 귀, 짧은 다리와 회색 발굽, 민트 리본 목걸이와 작은 금색 방울. 예진이보다 조금 작음.
- Clover Meadow: 클로버와 노랑·코럴 들꽃이 핀 언덕 들판, 오른쪽 큰 둥근 나무와 흰 울타리, 왼쪽 앞 맑은 얕은 웅덩이와 갈대, 멀리 초록 언덕과 작은 빨간 헛간.
- 먼저 **라인업 1장**(L00: 들판에 예진이·양·Pip)을 만들어 검수한 뒤 모든 시작 프레임의 참조로 씁니다(참조: 캐스트 d48b6ee4, Lily Pond 30a41807은 풀·하늘 스타일만).
- 위험: 양의 귀가 예진이에게 옮겨 붙을 수 있음 → 모든 카드에 예진이 "no visible ears" 고정, 양의 귀는 털 속에 납작하게.

## 4. ep2·ep3 교훈 반영

- 하늘 고정, 머리 비율 고정, 실시간 움직임, "gentle/slow" 금지, 연속 슬롯 각도 다르게, 시작 프레임에 있는 캐릭터만 이름.
- ep3에서 4번 나온 "t=0 배경 사라짐" 문제 → **모든 카드에 처음부터 배경 고정 문장**을 넣었습니다.
- ep3 자막이 작았던 문제 → 가사 한 줄씩, 최소 90pt, 긴 가사 슬롯은 와이드·미디엄 샷으로 배치.
